# CampusPass CA-1

## JavaScript files

- 00_globals.js - shared DOM elements and application state
- 01_storage.js - localStorage, sessionStorage and JSON
- 02_data.js - demo events and faculty accounts
- 03_helpers.js - small reusable functions and validation helpers
- 04_auth.js - Student/Faculty login and signup
- 05_event_cards.js - event cards and DOM creation
- 06_home.js - home page and category buttons
- 07_browse_events.js - search, filter and sort
- 08_event_details.js - event details and countdown
- 09_student_booking.js - student application, validation and payment (without event questions)
- 10_student_tickets.js - tickets and cancellation
- 11_faculty_post.js - faculty event creation and validation
- 12_faculty_events.js - faculty events and editing
- 13_fetch_api.js - Fetch API, Promise, async/await and JSON
- 14_navigation.js - page navigation and click delegation
- 15_nav_actions.js - profile and logout
- 16_app_start.js - application startup

`script_all_in_one.js` is included as a reference copy of the same JavaScript before it was divided into files.

Open `index.html` in a browser to run the project.
